# 个人档案内容

`archives.json` 是档案正文、个人概览与 TXT 导出的共同数据源。

五类分别为基本介绍、教育背景、项目经历、校园经历、联系方式。每类一份，共五份完整档案；研究兴趣归入基本介绍，三个开源项目归入项目经历。保留五列，每列条目数一致；编号按 `X-001` 递增。`categories` 控制检索顺序，`columns` 控制三维阵列顺序。

每份档案包含标题、中英文名称、归属、分类、时间、关键词、类型、概述、详情和相关链接。`links` 可选，使用 `https://`、`http://` 或 `mailto:`。内容按纯文本渲染。

个人资料依据本人提供的信息和已确认的公开主页。研究兴趣保持为学习方向；项目描述聚焦具体修复、资料贡献与协作方式。不要在公开内容中添加手机号、生日、籍贯、政治面貌、成绩或排名。

修改后运行：

```sh
npm run export:archives
npm run check:content
npm run build
```
